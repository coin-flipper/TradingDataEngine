**Early Development — Not Ready for Production**

# TradingDataEngine

A C# project for building a market data processing engine.

## Goal

The goal is to process market data, detect market features, and prepare structured datasets for future backtesting and trading applications.

## Planned Features

- OHLC data processing
- Candlestick pattern detection
- Market structure detection
- Technical indicators
- Trading sessions
- Order blocks
- Bid/Ask simulation
- Data storage
